# Sigma BC 1009 Mechanical Interface (reverse engineered)
This project provides a recreation of the original BC 1009 Twist Lock System backplate (what I call the "mechanical interface" here).
That's the essential part that allows the speedometer to be attached and detached from your bike's handlebar with a simple twist of the hand while providing a firm an secure mechanical connection to your bike.
I simplified it a little bit, as the original part showed at several places it was originally designed to support various models of Sigma's speedometers.

Now, the simplified part will also prove to be more durable than the original one, as it has less holes and features.

# Tools
The CAD file was generated by FreeCAD 1.0.2.
